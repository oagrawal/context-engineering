# Context Engineering Tool

This is an MCP server that lets you manage context for LLM agents using a git-like workflow. You can save commits to branches, create new branches, merge them together, and retrieve past context when you need it. Everything gets stored in a local `./context/` folder with branches and commits organized just like git.

To get started, install the dependencies with `pip install -r requirements.txt` and check out [SETUP_GEMINI_CLI.md](SETUP_GEMINI_CLI.md) for configuration. Once it's set up, you can just ask your AI assistant to save context or create branches and it'll handle the rest automatically.
